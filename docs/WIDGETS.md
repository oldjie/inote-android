# 桌面笔记小组件

应用提供两种 Android 窗口小工具，无需联网、后台常驻或额外系统权限：

- **快捷记录**：默认 2×2，显示「记录灵感 / 你在思考什么？」和新建按钮，点击进入应用记录。
- **笔记便签**：默认 4×2，可横向和纵向调整大小，选择指定笔记并自动显示更新后的文字。提供纸张、木纹、天空外观，以及大字标语模式；高亮、粗体和待办标记保留为可显示的文字样式。

便签显示的是选中笔记的文字摘要。图片显示为「[图片]」，长内容会根据空间截断；轻点便签进入应用阅读全文。点击便签右上角的三个点，可重新选择笔记、外观和大字模式。

## 在鸿蒙 4.2 添加

1. 安装并打开应用，创建至少一篇笔记。
2. 在手机桌面双指捏合，打开「服务卡片」。
3. 向下滑至底部，进入「窗口小工具」。
4. 找到「灵感笔记 · 快捷记录」或「灵感笔记 · 笔记便签」，长按并添加至桌面。
5. 添加笔记便签时选择笔记和外观，点「完成」。长按已添加的便签，可在桌面支持时调整大小。

上述入口依据华为适用于 HarmonyOS 4.2 的[窗口小工具帮助](https://consumer.huawei.com/cn/support/content/zh-cn15978796/)。不同桌面版本的入口和可用尺寸可能有差异。

本功能采用 Android `AppWidgetProvider` / `RemoteViews`，属于 APK 应用的窗口小工具，**不是鸿蒙原生服务卡片**。目标为能够安装本应用 APK 的 HarmonyOS 4.2；不宣称支持 HarmonyOS NEXT。开发验证使用 Android 模拟器，尚未在用户的鸿蒙 4.2 真机验证添加、调整大小和系统后台限制。

## 更新与数据

应用成功保存修改后会合并刷新请求，在后台更新已添加的小组件。系统重新加载小组件或调整大小时也会重新读取本机数据；不使用定时联网和常驻服务。

笔记移入回收站或归档后，小组件隐藏正文并提示重新选择；永久删除后不再显示旧内容。只读笔记可以阅读，便签不会直接修改它。移除小组件只删除其显示配置，不删除笔记。

小组件内容会交给桌面程序显示，也可能被桌面缓存。请选择适合在桌面可见的笔记。应用不把正文放进广播、链接参数或外部文件中。打开笔记的 PendingIntent 为不可变对象，入口验证当前组件与私有随机凭据，防止外部应用仅伪造 action/id 触发操作。

如果看不到新组件，先确认已打开一次应用、手机仍使用支持 APK 的系统，再重新进入桌面小工具列表。系统强制停止应用后，重新打开应用再检查；不需要关闭系统安全功能。

## 开发与验证

相关代码：`WidgetSupport`、`NoteWidgetProvider`、`QuickNoteWidgetProvider`、`NoteWidgetConfigActivity`。

`NoteWidgetTest` 包含 RemoteViews 渲染、回收站/归档隐藏、配置恢复、输出长度、链接清理、实际 AppWidgetHost 绑定与配置界面、调整大小和更新检查。主机绑定测试临时采用测试进程的 shell 权限；正式 APK 不申请 `BIND_APPWIDGET` 权限。

实现遵循 Android 官方的[小组件配置](https://developer.android.com/develop/ui/views/appwidgets/configuration)与[更新规则](https://developer.android.com/develop/ui/views/appwidgets/advanced)。最终测试结果以项目 README 中本次验证记录为准。
